# Live integrations verification

Date: 2026-10-08. Status: implemented and integration-specific checks passed locally; no live provider credentials supplied. Existing repository blockers are recorded separately.

## Implemented story

An Administrator prepares a connection without keys, maps an external campaign to a local campaign-platform, and enables daily sync. Once operator-managed read-only access tokens and supported API versions are configured, the API fetches bounded provider responses. Matched daily advertising observations become raw performance records consumed by existing analytics/reports; cumulative Zoho snapshots remain in run history. Missing configuration is visible and makes no provider call. Management reads results; Marketing Officers can manually sync configured sources.

## Coverage and practical limits

Fixture tests cover publisher separation, daily scope, campaign/account/currency validation, fixed-origin pagination, missing/zero values, malformed provider responses, safe HTTP errors, and Zoho cumulative totals. Database/HTTP tests cover all roles, anonymous access, Origin/CSRF, input validation, account/mapping uniqueness, foreign-key/integrity guards, missing credentials without requests, idempotency, owned corrections, manual/archived protection, currency/timezone blockers, scheduler backoff/restart, inactive authority, and disconnect fencing.

The golden advertising case imports 400 impressions, 10 clicks, and 42.5 spend: existing backend analytics returns CTR 2.5 and CPC 4.25. Date filtering, missing/zero denominators, report/PDF reads, protected file merges, and manual ownership removal are covered without adding KPI formulas. React review checked stable component identities, user-scoped queries, conditional run queries, accessible labels/statuses, backend-owned calculations, and responsive layout. No secret values are rendered or posted by the UI.

The passing Administrator browser journey creates/maps a connection without a provider token, enables scheduling, observes a `CREDENTIALS_REQUIRED` blocked run, checks run history, and disconnects while retaining setup/history. Separate Marketing Officer and Management journeys verify the absence of administrative configuration controls. At 390px, document width fits the viewport; visual inspection of the captured mobile screen confirmed stacked cards/forms and a contained horizontally scrollable run-history table.

No live API approvals, real account permissions, network requests, or token validity have been verified. Meta's direct developer documentation was rate-limited; request shape was checked against its maintained API collection and synthetic fixtures. LinkedIn daily data is UTC and cannot be combined into differently bounded reporting days from daily totals; such imports are blocked. Zoho cumulative snapshots do not enter daily analytics. Tokens require operator replacement when expired; browser OAuth and automatic refresh are not included. Unnamed additional providers require separate adapters. External deployment was not performed.
