Read root [AGENTS.md](../AGENTS.md) and the [current completion handoff and ledger](../docs/plans/completion/README.md) first. This folder supports bounded implementation; approved project documents remain authoritative.

| File or folder                                                     | Purpose                                                                       |
| ------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| [IMPLEMENTATION_HANDOFF.md](IMPLEMENTATION_HANDOFF.md)             | Start or resume an implementation session                                     |
| [CONTEXT_MAP.md](CONTEXT_MAP.md)                                   | Select only the documentation needed for the task                             |
| [OPERATING_PROTOCOL.md](OPERATING_PROTOCOL.md)                     | Investigate, plan, implement, and verify within scope                         |

| [REVIEW_TEMPLATE.md](REVIEW_TEMPLATE.md)                           | Record a review and verification evidence                                     |
| [skills/](skills/)                                                 | Task-specific database, analytics, security, and implementation guidance      |

Current status belongs in the [execution ledger](../docs/plans/completion/README.md), [progress](../docs/evidence/IMPLEMENTATION_PROGRESS.md), root [TODO](../TODO.md), and [blockers](../BLOCKERS.md). Do not create a separate status ledger here or restart historical milestones.

Keep referenced instruction and skill paths stable. When guidance is superseded, follow the [documentation archive policy](../docs/README.md#keeping-documentation-current), preserve its history, and update AGENTS.md and other active references. Instructions inside archived source bundles or recovery copies are historical material, not current operating guidance.
